# Contributing to [Let's Do] Sleepy Hollows

In Sleepy Hollows, where shadows creep,  
The code must wake from haunted sleep.  
Each line you write, each change you send,  
Should help this eerie tale extend.

Pull Requests rise in candle’s glow,  
But tidy work must always show.  
For messy code or ghostly trace  
May stir the riders from their place.

---

## How You Can Help

- **Pull Requests (PRs)**: Bring forth your craft beneath the moon.  
  Keep it clean and neat — review comes soon.
- **Feature Requests**: Speak your dreams aloud and clear.  
  New horrors thrive when shared right here.
- **Bug Reports**: When phantoms crawl or errors bite,  
  Describe them well beneath the night.

---

## Guidelines

Clean and ordered, dark yet fair,  
Let no unused relic linger there.  
Each message told, concise and neat,  
Should guide the lost through code’s cold street.  
(Conventional commits are a charm of might,  
They bind the changelogs through the night.)

---

## Code Style

Follow the flow that’s set before,  
The pattern old — the ghostly lore.  
Ensure your code builds without fright,  
Before it joins the sleepless night.

---

## Testing

Where lanterns fade and features stir,  
Test what you’ve made, ensure no blur.  
Explain your work so all may learn,  
And keep the haunted balance turn.

---

So welcome, traveler, to this domain,  
Where whispers hum through fog and rain.  
Your code shall grow, your legend call —  
And live within Sleepy Hollows’ thrall.
